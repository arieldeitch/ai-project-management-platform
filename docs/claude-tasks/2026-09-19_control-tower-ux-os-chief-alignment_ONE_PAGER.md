# Control Tower — UX + OS Alignment + Chief of Staff integration

Date: 2026-09-19
Status: APPROVED FOR IMPLEMENTATION

## North Star
Compact, calm Control Tower that tells Ariel only what matters, while proving that every managed app is aligned with the canonical AI OS.

## User-visible priorities
1. Compact Home / Projects / Ideas; details on demand.
2. Home status filtering + clear status meaning.
3. Optional one-line project purpose.
4. Fast/background Ideas refresh + drag reorder.
5. Pleasant visual language; remove harsh black/blue feel.
6. Hebrew Ariel-facing communication.
7. Deputy outputs actions, not developer jargon.
8. Version/build/branch/commit freshness shown compactly where useful.
9. Per-project OS alignment: CURRENT / VERSION_DRIFT / NEVER_SEEN / ACCESS_FAILED / UNKNOWN.
10. Chief of Staff consumes the same truth and translates it into concise actions.

## Boundaries
- OS owns rules.
- Control Tower owns portfolio evidence and OS-alignment visibility.
- Chief of Staff owns prioritization/action translation.
- Child projects own implementation truth.
- No competing registry/backend.

## Product gate
Engineering may become GREEN after tests/build; Product remains USER TEST REQUIRED until Ariel validates on phone.
